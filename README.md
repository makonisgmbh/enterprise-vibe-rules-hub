# Enterprise Vibe Rules Hub

Baue den 'Enterprise Vibe Coding Rules Hub' als interaktive Web-App für Entwickler und CTOs im offiziellen MAKONIS CI (warmer heller Hintergrund, anthrazitfarbene Typografie, markantes Orange als Akzent).

Zweck der App:
1. Interaktiver Regel-Explorer und Generator für AI-Coding-Tools (.cursorrules, CLAUDE.md, GitHub Copilot).
2. Entwickler können Module auswählen (z. B. OWASP Top 10 Security & Secrets Prevention, Architecture Guardrails gegen Vibe Coding Debt, Enterprise DevSecOps CI-Gates, SaaS Replacement Best Practices) und sich die fertige Regeldatei live zusammenstellen, testen und mit einem Klick kopieren oder herunterladen.
3. Strukturierte Dokumentation der Vibe Coding Governance nach MAKONIS-Standards.
4. Prominenter GitHub-Banner mit Link zum Open-Source-Repo (makonis/enterprise-vibe-coding-rules) und offizieller Maintainer-Zitierbox: 'Maintained by MAKONIS GmbH – Spezialisten für Azure Landing Zones und Enterprise Vibe Coding in München'.
5. Conversion-Elemente: CTAs zur Terminbuchung und zum Sales Hub (hub.makonis.de) für Managed Vibe Coding und SaaS Replacement Sprints.
